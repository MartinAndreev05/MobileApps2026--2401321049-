ПЛАН ЗА КОМИТИ – MobileApps2025-<ФН>
========================================
Цел: оценка 6 (100 т.)
Проект: Kotlin, пакет bg.uni_plovdiv.fmi.mobileapps, Min SDK 24, Target SDK – последната стабилна версия
Архитектура: MVVM + Repository + DI (Hilt)

Забележка: По-долу основният обект е наречен "Item" (напр. задача, бележка, място и т.н.).
Замени го с обекта на твоето приложение.

Общи правила:
- Комитвай веднага след всяка стъпка и пиши смислени съобщения (на английски или на български, но еднакво навсякъде).
- Push-вай редовно, не всичко накрая (оценява се "реална Git история" и срокове).
- След всеки комит проектът трябва да се компилира и стартира.
- Ако ти остава време, раздели по-големите стъпки на 2–3 по-малки комита.

----------------------------------------------------------------
КОМИТ 1 – Първоначален проект
----------------------------------------------------------------
Съобщение: "Initial commit: Android project setup"
- git init, създаване на публично репо MobileApps2025-<ФН> в GitHub
- Проверка на .gitignore (build/, .gradle/, local.properties, *.iml, .idea/)
- minSdk = 24, targetSdk/compileSdk = най-новата стабилна версия
- Празна MainActivity, която се стартира без грешки
Точки: Компилация и старт (5 т.)

----------------------------------------------------------------
КОМИТ 2 – Тема Material 3 (light/dark)
----------------------------------------------------------------
Съобщение: "Add Material 3 theme with light and dark mode"
- Зависимост com.google.android.material
- Theme.Material3.DayNight в values/themes.xml и values-night/themes.xml
- Цветова палитра в colors.xml, текстовете в strings.xml (без hardcoded текст)
- Иконка на приложението
Точки: UI/UX (5 т.)

----------------------------------------------------------------
КОМИТ 3 – Навигация между екраните
----------------------------------------------------------------
Съобщение: "Add Navigation Component with list and detail fragments"
- Navigation Component + nav_graph.xml
- Фрагменти: ItemListFragment, ItemDetailFragment (добавяне/редакция), по желание SettingsFragment
- Toolbar/TopAppBar с бутон "Назад", FloatingActionButton за добавяне
Точки: Навигация >= 2 екрана (5 т.)  → тук вече е покрита оценка 3

----------------------------------------------------------------
КОМИТ 4 – Room база данни
----------------------------------------------------------------
Съобщение: "Add Room database with Item entity and DAO"
- Зависимости за Room (runtime + room-ktx + KSP компилатор)
- Entity: Item (id, title, description, createdAt, ...)
- ItemDao: insert, update, delete, getAll (LiveData<List<Item>>), getById
- AppDatabase (singleton)
Точки: Локална БД (10 т.)

----------------------------------------------------------------
КОМИТ 5 – Repository + ViewModel (MVVM)
----------------------------------------------------------------
Съобщение: "Introduce Repository layer and ViewModels (MVVM)"
- ItemRepository – единствената точка за достъп до данните; DB операциите са suspend функции / Flow (корутини, не в UI нишката)
- ItemListViewModel, ItemDetailViewModel
- Фрагментите наблюдават LiveData с getViewLifecycleOwner() (важно за липса на memory leaks)
Точки: Архитектура (част от 10 т.)

----------------------------------------------------------------
КОМИТ 6 – Create + Read през UI
----------------------------------------------------------------
Съобщение: "Implement create and list items (RecyclerView)"
- RecyclerView + ListAdapter с DiffUtil, MaterialCardView за елементите
- Форма за добавяне (TextInputLayout) с валидация на полетата
- Празно състояние ("Няма записи") при празен списък
Точки: → оценка 4

----------------------------------------------------------------
КОМИТ 7 – Update + Delete (пълен CRUD)
----------------------------------------------------------------
Съобщение: "Implement update and delete operations"
- Клик върху елемент → отваря се за редакция (подаване на id чрез Safe Args / Bundle)
- Изтриване: swipe-to-delete или бутон + потвърждение с MaterialAlertDialog
- Snackbar с "Отмени" след изтриване (бонус за UX)
- Проверка: данните остават след рестарт на приложението
Точки: CRUD цялостно (15 т.)  → оценка 5

----------------------------------------------------------------
КОМИТ 8 – Dependency Injection (Hilt)
----------------------------------------------------------------
Съобщение: "Add Hilt dependency injection"
- @HiltAndroidApp Application клас
- Модул DatabaseModule, който предоставя AppDatabase, ItemDao, ItemRepository
- @HiltViewModel за ViewModel-ите, @AndroidEntryPoint за Activity/фрагментите
Точки: Архитектура – DI (допълва 10 т.)

----------------------------------------------------------------

----------------------------------------------------------------
Съобщение: "Add REST API integration with Retrofit"

- Например: зареждане на данни/импорт от публично API или показване на допълнителна информация
- Обработка на грешки (няма интернет, timeout) + индикатор за зареждане
- Мрежовата логика минава през Repository (отделен RemoteDataSource)
Точки: Допълнителна функционалност (20 т.)  → оценка 6

----------------------------------------------------------------
КОМИТ 10 – Допълнителна функционалност #2 (Share Intent / Camera / QR)
----------------------------------------------------------------
Съобщение: "Add share intent and camera photo attachment"
- Share Intent: споделяне на запис като текст (ACTION_SEND)
- По желание: Camera Intent за снимка към записа (FileProvider + runtime permissions)
- Правилна заявка за разрешения (ActivityResultContracts) – питат на защитата за permissions
Точки: подсигурява 20 т. + бонус (0–5 т.)

- Изтриване на ExampleUnitTest
Точки: Тестове (част от 5 т.)
